## Getting Started

### 1. Install a C++ compiler

You will need a C++ toolchain such as:

- `g++` on Linux/macOS
- MinGW or MSYS2 on Windows
- `clang++` as an alternative compiler

### 2. Clone the repository

```bash
git clone https://github.com/liewvk/CppME_Chapter12.git
cd CppME_Chapter12
```

### 3. Compile a C++ file

For a single-file program:

```bash
g++ main.cpp -o main
```

If the file is named differently, replace `main.cpp` with the relevant source file.

### 4. Run the program

```bash
./main
```

On Windows, the executable may be:

```bash
main.exe
```

## Example Build Workflow

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o main
./main
```

The `-std=c++17` flag ensures modern C++ features are available, and the warning flags help catch common errors while learning.
